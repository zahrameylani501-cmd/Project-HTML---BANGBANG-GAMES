# BangBang Games
BangBang Games adalah katalog game gratis (free-to-play) yang dibuat menggunakan HTML, CSS, dan JavaScript. Project ini menampilkan daftar game dari berbagai genre lengkap dengan fitur pencarian, filter, dan detail game, sehingga pengguna bisa dengan mudah menemukan game gratis yang sesuai dengan minat mereka.

## Deskripsi
Project ini merupakan aplikasi web katalog game yang mengambil data secara langsung dari FreeToGame API. Seluruh tampilan dibangun secara dinamis menggunakan JavaScript (DOM generation).

## Fitur Utama
- Pencarian Game - mencari game berdasarkan judul
- Filter Kategori - menyaring game berdasarkan genre atau platform atau sort
- Favorit - menandai game favorit untuk akses cepat
- Detail Game - menampilkan informasi lengkap game dalam tampilan pop-up
- Multi-Halaman - terdiri dari beberapa halaman yang saling terhubung
- Integrasi REST API - mengambil data game dari FreeToGame API

## Cara Menjalankan
1. Clone atau download repository ini
2. Buka folder project
3. Jalankan file index.html dengan cara membukanya langsung di browser
4. Pastikan koneksi internet aktif, karena data game diambil langsung dari API
